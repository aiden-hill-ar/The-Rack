# The Rack

## What is it?

It's currently only a calculator that can do basic math

I planned on making The Rack a list of tools that you could use, but I shifted my attention elsewhere and decided a simple calculator that functions mostly as intended was enough.

## Why was it made?

I made The Rack after making the calculator tool in it first. I had an idea for multiple tools to live in one space called The Rack, but turns out I only ended up making the calculator tool.

I made the calculator tool to solve the necessity of a *good,* physical feeling calculator on desktop.

## Important

**The Rack is done, and it's not great**

While the state The Rack is in isn't the best to say the least, I'm not too worried about it because I have shifted my attention over to other projects.
